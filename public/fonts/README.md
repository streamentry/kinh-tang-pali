# Fonts

Self-hosted WOFF2 from npm `@fontsource/noto-serif@5.3.0` and
`@fontsource/be-vietnam-pro@5.3.0`. Both use SIL Open Font License 1.1;
original notices are preserved beside the files. Only Latin, Latin extended
and Vietnamese subsets are shipped. Unicode ranges in `../styles/fonts.css`
let the browser load only the subsets and weights the page uses.

Noto Serif: 400 normal, 600 normal, 400 italic. Be Vietnam Pro: 400 and 600 normal.
These third-party fonts retain their own licenses and are not project CC0 content.
