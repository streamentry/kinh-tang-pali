# Roadmap

## Phase 1 — Majjhima Nikāya

1. Vertical slice MN118: pinned Pāli → segmented Việt → web reader → Pagefind → EPUB/PDF.
2. Chốt quy ước dịch + glossary + human review gate.
3. Dịch/review lần lượt MN theo catalog `mn1` → `mn152`.
4. Chỉ khi pipeline MN ổn định mới mở rộng corpus tiếp theo.

## Phase 2 — Four remaining Nikāyas

Khung namespace đã tồn tại cho:

- `dn` — Dīgha Nikāya / Kinh Trường Bộ
- `sn` — Saṁyutta Nikāya / Kinh Tương Ưng Bộ
- `an` — Aṅguttara Nikāya / Kinh Tăng Chi Bộ
- `kn` — Khuddaka Nikāya / Kinh Tiểu Bộ

Không phát minh catalog SN/AN/KN bằng arithmetic. Khi bắt đầu mỗi bộ, import canonical tree/UID/source paths từ pinned SuttaCentral snapshot vào catalog project.
